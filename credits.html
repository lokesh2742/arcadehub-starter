Credits & Licences

ArcadeHub is built using web technologies and third-party services. This page identifies the key infrastructure currently used by the project.

ArcadeHub project

The ArcadeHub website layout, game interfaces and project code are maintained in the ArcadeHub GitHub repository. Game implementations and visual elements may evolve as the project develops.

Firebase

Online multiplayer uses Firebase Authentication and Firebase Realtime Database, provided by Google. Firebase is a third-party service and is subject to Google's applicable terms and privacy documentation.

Browser technologies

The site uses standard HTML, CSS and JavaScript, along with browser APIs for local storage, keyboard/touch interaction and canvas rendering where needed.

Third-party assets

Some game symbols and decorative visuals use standard Unicode characters and emoji rendered by the player's device. Any third-party libraries, fonts, images or other assets added in future updates must be used in accordance with their respective licences and attribution requirements.

Questions about credits

If you believe an asset has been used incorrectly or an attribution is missing, please let us know through the Contact page with the relevant details.
