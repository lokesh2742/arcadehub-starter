Contact ArcadeHub

Found a bug, have a game idea, or want to share feedback? Use the project's public issue tracker so the report can be followed up.

Best way to reach the project: Open ArcadeHub on GitHub and create an issue.

What to include in a bug report

  • The game or page where the problem happened.
  • The steps you took before the issue appeared.
  • What you expected and what actually happened.
  • Your browser, device type and any error message (a screenshot can help).

Keep your information safe

The GitHub issue tracker is public. Do not include passwords, private room codes, personal phone numbers, home addresses or other sensitive information. If you need to discuss something private, do not post it in a public issue.

Game suggestions

Tell us the game's name, why you would like to see it on ArcadeHub and whether you imagine it as a solo or multiplayer game.
