# Blockfront asset sources and licence notes

The current browser build uses original procedural Three.js geometry for its arena props, player silhouettes, weapon viewmodel and bot models. No third-party model files are bundled yet; this avoids importing assets with unclear redistribution terms.

Open-source sources selected for the next art pass:

- [Kenney 3D assets](https://kenney.nl/assets) — Kenney states its game assets are CC0 and usable commercially; verify the individual pack's included licence file when downloading.
- [Kenney animated characters](https://kenney.nl/assets?series=Animated+Characters) — animated low-poly character packs; CC0 as stated on the individual pack pages.
- [Quaternius Sci-Fi Essentials Kit](https://quaternius.itch.io/sci-fi-essentials-kit) — includes textured guns, animated enemies, crates and props; the pack page states CC0.
- [Quaternius Ultimate Animated Character Pack](https://quaternius.com/packs/ultimateanimatedcharacters.html) — character source; verify current pack page licence and formats before importing.
- [Quaternius Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) — retargetable character animation clips; verify current pack page licence before shipping.

Keep each downloaded pack's original licence file in the repository. Do not bundle marketplace previews or assets unless the individual asset's licence explicitly permits redistribution.
